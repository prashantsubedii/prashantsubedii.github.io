# Frames

Add your event, hackathon and technology-community photos here. Nested folders work too.

Supported browser image formats: JPG, JPEG, JFIF, PNG, WebP, AVIF, GIF, SVG, BMP and ICO (case insensitive). Export HEIC/TIFF camera originals as JPG or WebP before adding them.

The Frames page automatically lists images in filename order and turns the filename into a caption. For example, `csitan-hackfest-2024.jpg` becomes “Csitan Hackfest 2024”. Descriptive names also improve image accessibility.

Refresh `/frames` during local development after adding files. For the live static website, commit the photos and rebuild/deploy the site. No code edits or CMS entries are needed.

Click a photo to open the full image; Escape closes the viewer.
